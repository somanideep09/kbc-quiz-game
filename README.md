# KBC Quiz Game

A Python-based KBC-style quiz game that fetches multiple-choice trivia questions from the Open Trivia Database API.

## Features

- Fetches questions automatically using an API
- Randomizes question order
- Randomizes answer options
- Multiple-choice gameplay
- Input validation
- API error handling
- Prize system
- Shows the correct option after a wrong answer

## Technologies Used

- Python
- Requests
- REST API
- JSON
